# Tidal Atlas
A bespoke Eastern North Carolina paddling field-guide portfolio concept by MozingoUX. All routes and organizations are fictional; the map is not for navigation.

## Run
Serve this folder using any static web server, e.g. `npx serve .`. There is no build step. GitHub Pages can publish directly from the repository root.

## Features
Responsive editorial design; original SVG route map; difficulty filters; route stories; persistent packing checklist with storage failure fallback; keyboard-friendly native controls; mobile navigation; reduced-motion support.

## Content and assets
All copy and map artwork created for this concept. Photo downloaded from Unsplash (`photo-1472396961693-142e6e269027`), used as evocative woodland imagery, not as a documented location. Fonts from Google Fonts with local system fallbacks. No analytics, remote form processing, or booking. Checklist is stored only on the visitor's device.
